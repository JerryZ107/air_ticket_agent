# 机型与座位布局

演示航线常用窄体机型（如 A320neo）总座位 **120**：**商务舱** **22** 座（第 1–3 排），**经济舱** **98** 座（第 4–31 排）。

**安全出口**排为第 **4** 排（经济舱前排出口）和第 **16** 排（翼上出口）。出口排座椅间距较大，但不得放置行李于脚边；旅客须满 15 周岁、具备中文或英文沟通能力、无行动不便。

# 选座时间与费用

订票时、出票后至值机截止前可在 App 选座。经济舱标准座位免费；前排优选座 50 元起；安全出口排 100 元（须现场复核资格）。

# 座位图说明

A/C 为靠窗，B 为中间（仅商务舱部分排），D/E/F 为过道侧。31 排部分座位靠背不可调。

# 特殊座位

婴儿摇篮位：第 11 排 A/B，限身高 75 厘米以下婴儿，须提前 24 小时申请。

轮椅旅客：优先安排靠过道及可拆卸扶手座位；不得占用出口排。

# 升舱与座位变更

登机口竞价升舱按当日价格；已购优选座升舱后原选座费不退差额部分按规则处理。

# 占座与骚扰

占座、强行换座、骚扰邻座将被警告并可能取消运输合同，已付选座费不退。
