# 机上 Wi-Fi

全舱提供**免费** **Wi-Fi**（基础浏览）。请在设备无线网络列表中选择 **Airline-Wifi**（SSID 显示为 **Airline**-Wifi），打开浏览器按提示**连接**并完成简单认证。

流媒体、视频会议需购买「高速包」：短途 68 元，长途 128 元，限单设备。支付支持机上扫码或里程兑换。

飞行关键阶段（起飞、着陆、低空）可能短暂中断服务。请勿使用 VoIP 电话以免干扰驾驶舱通信。

# 电源与娱乐

经济舱每排配备 USB-A 充电口；商务舱提供 110V 插座。座椅背屏提供电影、剧集、音乐及飞行地图；可连接蓝牙耳机（单设备）。

# 餐食与饮品

飞行时间 2 小时以内：小食与矿泉水。2–4 小时：热食或三明治套餐。4 小时以上：正餐轮换中式/西式。

特殊餐食代码：VGML 素食、MOML 清真、CHML 儿童餐、DBML 糖尿病餐，须起飞前 24 小时预订。

酒精饮料：商务舱含葡萄酒与啤酒；经济舱付费购买。未满 18 周岁不得饮酒。

# 客舱卫生与舒适

提供毛毯、枕头（长途）；建议自备颈枕。客舱温度约 22–24℃，可调整个人出风口。
