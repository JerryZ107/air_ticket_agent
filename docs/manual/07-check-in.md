# 值机时间

网上/手机值机：国内航班计划起飞前 48 小时至起飞前 2 小时开放；国际航班起飞前 24 小时至起飞前 90 分钟。

机场柜台值机截止：国内航班起飞前 45 分钟；国际航班起飞前 60 分钟（部分机场 75 分钟）。

# 登机时间

登机口于计划起飞前 40 分钟开放，起飞前 20 分钟关闭。晚到旅客须改签或退票，不得强行登机。

# 证件要求

国内：有效居民身份证、护照、军官证等。国际：护照有效期须超过目的地入境要求（通常 6 个月），持有效签证或免签证明。

# 电子登机牌

App 电子登机牌与纸质登机牌同等效力；截图可能因动态条码失效，请使用 App 实时码。

# 行李托运柜台

值机同时托运行李须完成称重贴条；自助托运机支持部分机场，最大单件 32 公斤。

# 安检与海关

国内航线：液体、凝胶 100 毫升限制。国际出境：完成海关申报后再安检。中转旅客遵循中转机场规则，详见国际旅行专题。
