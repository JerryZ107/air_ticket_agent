# 国际旅行证件

出境中国大陆须持有效护照及目的地签证（或免签/落地签资格）。入境美国须 ESTA 或签证；申根区须 Schengen 签证。旅客自行负责证件有效性。

# 中转与过境

24 小时内国际中转且不离开隔离区，部分航线免过境签证；离开隔离区进入当地须符合该国入境政策。联程行李直挂以出票时系统显示为准。

# 海关申报

携带超过 1 万元人民币等值现金须申报。动植物制品、肉类制品多数国家禁止入境。回国须遵守中国海关个人物品限额。

# 健康与检疫

部分目的地要求疫苗接种证明或健康申报。发热旅客可能被拒绝登机或隔离，票款按自愿退票处理。

# 时差与行程单

电子行程单可在 App 下载英文版，用于签证与报销。航班时刻均为当地时间，旅客须自行换算。
