# 超售与拒绝登机

航班超售时，自愿让出座位的旅客可获得协商补偿（代金券或现金）及改签至下一航班。非自愿拒绝登机按法规标准补偿。

# 机上行为

扰乱秩序、吸烟（含电子烟）、不系安全带、破坏设备将移交警方，并列入承运人黑名单。

# 天气备降

备降他站时，承运人提供餐饮与住宿协调；后续运输免费送至目的地或退票。

# 代码共享

票面承运人代码与实际承运人可能不同，行李直挂与休息室权益以实际承运为准。投诉可先向销售承运人提出。

# 数据与隐私

旅客个人信息用于运输合同履行及安全目的，不出售给第三方。营销订阅可单独取消。

# 争议解决

协商不成可向民航服务质量监督平台投诉，或向承运人所在地人民法院提起诉讼（国内航线）。
