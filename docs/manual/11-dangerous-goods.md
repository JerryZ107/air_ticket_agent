# 锂电池与充电宝

随身携带：额定能量不超过 100Wh 无需航空公司批准；100–160Wh 须航空公司批准，每人最多 2 块。超过 160Wh 禁止携带。

充电宝须有清晰容量标识，无标识可能被安检没收。飞行中不得使用充电宝充电，须关闭电源。

# 液态物品

随身携带液体、凝胶、气溶胶每容器不超过 100 毫升，全部放入 1 升透明可封口塑料袋，每人一袋。药物、婴儿食品可豁免但须接受检查。

# 常见禁运品

打火机、火柴禁止托运及随身（部分机场允许少量随身打火机，以当地为准）。刀具、工具须托运并符合长度限制。电子烟禁止托运，随身规则按出发国执行。

# 危险品申报

旅客携带弹药、化学品、干冰、医用氧气等须提前 72 小时向承运人申请批准号。
