# 场景：出差临时改晚一班

旅客：「我会议延长了，能改今晚下一班吗？」  
政策：起飞前 2 小时前自愿改签，收改期费并补差价；在同一确认号上办理，确认号不变。若仅晚 1–2 小时且同航线有余票，Y/B 舱可免改期费。

# 场景：带吉他上飞机

吉他可作为随身物品若符合 56×36×23 厘米；超长须购买额外座位或托运并加保护包装费 50 美元。

# 场景：滑雪板托运

按特殊行李收运，计入托运行李件数，超尺寸附加 50 美元/件，须提前 48 小时预约。

# 场景：充电宝 20000mAh

约 74Wh，可随身携带，每人限 2 块；飞行中不得充电。无容量标识可能被安检拒绝。

# 场景：化妆品 150ml 托运

托运不受 100ml 限制；随身仅 100ml/瓶。建议液体放托运以防安检没收。

# 场景：航班取消后怎么办

非自愿改签免手续费免差价，或全额退票。住宿餐饮按延误补偿章节约 3 小时标准执行。

# 场景：只退返程票

往返票去程已使用后，返程按未使用段退票规则，扣除相应手续费。

# 场景：买错日期

属自愿改签，改期费+差价；若新航班更便宜，差价不退（除非政策促销另有说明）。

# 场景：身份证丢了还能飞吗

国内航班可凭公安机关出具的临时身份证明乘机；国际航班须有效护照，无替代证件。

# 场景：带婴儿推车

婴儿车可免费托运；可折叠小型推车部分机型允许带入客舱尾部，以现场为准。

# 场景：宠物猫进客舱

部分国内航线接受，笼具+宠物≤8kg，每航班限 2 只，须预约并付宠物运费。

# 场景：导盲犬

服务犬免费进客舱，不占宠物配额，提前 48 小时备案。

# 场景：金卡免费改签

白金卡每年一次免费自愿改签；金卡免改期费但仍可能补舱位差价。

# 场景：里程换票能退吗

未使用可退回里程，扣除退票手续费对应的里程；部分促销兑换票不可退。

# 场景：登机口升舱

竞价升舱短信/App 推送，最低 299 元起，售罄即止。

# 场景：选座后改签

改签后原座位失效，须重新选座；已付选座费不退，新航班重新购买或按舱位权益免费。

# 场景：延误 2 小时有餐吗

未满 3 小时一般不触发正式补偿套餐，地服可酌情发饮料券；满 3 小时发正式餐券。

# 场景：错过后续国际联程

承运人原因免费改签下一班；非承运人原因按客票规则，可能收差价。

# 场景：酒店自己订能报销吗

凭收据、登机牌、延误证明，21 日内申请，交通上限 200 元/程，酒店按券额或实报实销规则。

# 场景：行李转盘没有我的箱子

凭行李条到行李服务柜台开 PIR，提交索赔跟踪；非旅客原因延误送达免费送到酒店。

# 场景：箱子摔坏了

现场检查并登记破损部位，7 日内申报；维修费或折旧赔偿协商。

# 场景：超售自愿让座

协商补偿+改签下一航班；非自愿按法规标准现金或代金券。

# 场景：机上 WiFi 看视频

基础 WiFi 免费浏览；视频需购高速包 68/128 元。

# 场景：能开公司发票吗

行程结束 30 日内 App 申请电子发票，填企业税号。

# 场景：儿童单独飞

5–12 岁须 UM 服务，提前 48 小时，国内 200 元/段。

# 场景：12 岁孩子单独飞

可不购 UM，但家长须签署免责声明；建议仍购 UM 服务。

# 场景：孕妇 30 周

须医生适宜乘机证明，32 周以上一般拒绝承运。

# 场景：轮椅到登机口

申请 WCHR/WCHS/WCHC，提前 48 小时，自有轮椅免费托运。

# 场景：中转只有 1 小时

MCT 不足可能导致无法衔接，订票时系统会提示；若前段延误导致错过，按非自愿改签。

# 场景：美国航线行李两件

洲际经济舱常含两件各 23 公斤，以出票记录为准。

# 场景：易碎瓷器托运

须签免责书，可办声明价值最高 5000 美元。

# 场景：打火机

禁止托运；随身按出发机场规定，多数禁止。

# 场景：电子烟

禁止托运；随身看当地法规，客舱禁止使用。

# 场景：占座吵架

乘务有权警告、调换座位或移交地面，严重取消运输。

# 场景：备降其他城市

免费提供后续运输或退票，餐饮住宿协调。

# 场景：代码共享谁负责

销售承运人受理投诉，实际承运人执行运输，行李以实际承运为准。

# 场景：OTA 买票退改

按出票时展示的客规，OTA 不得加价退改费。

# 场景：重复扣款

核实双订单后退一张，非自愿退票路径。

# 场景：系统标价 1 元

明显错误可取消订单全额退款。

# 场景：黑名单能飞吗

列入拒绝运输名单者购票无效，已购按自愿退票扣费处理。
