# 购票渠道

官网、App、客服、授权代理人、OTA 平台均可购票。不同渠道退改规则以出票时展示的运输总条件为准，代理人不得擅自修改。

# 支付方式

支持银联、Visa/Mastercard、支付宝、微信支付、Apple Pay。企业客户可申请月结 UATP。

# 票价构成

票价 + 民航发展基金 + 燃油附加费 + 可选服务费。儿童票为成人适用票价的 50%（无座婴儿 10%）。

# 客票有效期

国内客票自出票之日起 12 个月内有效；国际按 IATA 规则，通常 12 个月。未使用航段过期后票款不予退还（特价舱除外）。

# 重复购票

同一旅客同一航班重复购票，核实后免费退其中一张（非自愿退票）。

# 价格错误

明显系统标价错误，承运人有权取消订单并全额退款，不承担额外赔偿。
