# 改签总则

**改签**指在同一 **Booking** 上变更所乘 **Flight**（日期、航班号或舱位），**确认号不变**。旅客可说「换一个航班」办理改签。

改签前系统须**锁定**新航班座位；锁定失败、支付差价失败或出票失败时，原订单**保持不变**，原座位与票款状态不受影响。

改签可能产生票价**差价**及改期手续费（自愿改签时）。差价按新航班开放舱位价格与旧票面价差计算，多不退少补（除非政策另有非自愿豁免）。

## 请勿先退票再重订

办理「换航班」时，**请勿**先**退票**再重新订票作为改签替代。正确路径为在原**确认号**上提交改签；先退后订将产生新确认号，可能导致原价舱位丧失、手续费重复收取。

# 自愿改签

起飞前 2 小时以前：经济舱改期费 200 元人民币/人（或 30 美元），商务舱免费改期一次（银卡及以上）。起飞前 2 小时内及起飞后：按误机改期规则，另收误机费 500 元起。

同日同航线改签到更晚航班，若新舱位有余票，可免收改期费仅补差价（限经济舱 Y/B 舱）。

# 非自愿改签

因承运人原因（航班取消、延误超 4 小时、机型调整、超售）导致无法成行，旅客可办理非自愿改签：免改期费、免差价（同等舱位），或签转至合作承运人（以联运协议为准）。

因天气、空管、公共安全等不可抗力，按运输总条件办理，可能收取舱位差价但不收改期费。

# 改签与退票的区别

**改签**保留原订单，仅变更航班信息，**确认号**延续。**退票**终止订单，座位**释放**，按退票规则退款。二者业务路径互斥；客服不得将改签引导为先退票。

# 联程与缺口程

联程客票部分航段使用，未使用段改签须整段重算票价。缺口程（OPEN JAW）改签受航线规则限制，须致电客服。

# 姓名与证件更正

 typo 姓名更正（同音字、个别字母）在起飞前免费一次；变更乘机人须退票重购，不属于改签。

# 改签后选座与服务

改签成功后原预选座位失效，须重新选座。特殊餐食、轮椅、无陪儿童等服务须重新申请。

# 确认号不变说明

**确认号不变**指对客展示的字母数字订单标识在整个改签成功后保持不变，便于旅客查询、报销与里程补登。仅 **New Booking**（全新订票）会生成新确认号。
