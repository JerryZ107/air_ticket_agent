# 延误补偿总则

**长时间延误**指计划起飞时间延误超过 **3** 小时，或实际到达延误导致旅客错过后续联程航班、且间隔时间不足 MCT（最短中转时间）的情形。

补偿形式包括：**酒店**住宿券、**餐券**、地面**交通**补贴、里程或旅行**积分**，以及现金补偿（仅限特定国际航线法规要求时）。

# 承运人原因延误

因机械故障、调配、机组、公司计划等原因，延误满 **3** 小时：发放餐券 50 元人民币等值/人；满 4 小时且需过夜：发放**酒店**券（标准间，上限 600 元/间/夜，双人同住一间）。

错过后续航班：免费改签至最近可用航班，或按旅客选择**退票**；地面**交通**至酒店或机场由地服安排或报销出租车费（凭**收据**，上限 200 元/程）。

# 非承运人原因

天气、空管流量控制、机场关闭、罢工（非本公司）、公共安全事件等，承运人提供协助但不承担法定赔偿义务；可酌情发放餐饮券。

# 申请流程

旅客向机场服务柜台、App 或客服说明确认号与延误事实。客服核实航班动态后**创建补偿案例**，系统发放电子券或积分。

**里程积分补偿**：金卡及以上或单次延误超 6 小时，可额外获赠 2000–10000 积分，视会员等级与延误时长浮动。

# 单据保留

自行垫付酒店、餐食、**交通**费用的，须保留正规**收据**及登机牌、延误证明，在抵达后 21 日内提交报销申请。

# 欧盟与美国航线提示

飞往/来自欧盟的航班，延误超 3 小时可能适用 EC261 现金补偿标准（与本公司券补偿择一，不得重复获利）。美国境内航线按 DOT 超售与延误告知义务执行。

# 行李与延误叠加

仅行李延误不自动触发客票延误补偿；但若因航班延误导致行李未能同机到达，适用行李免费送达政策，见行李专题。
